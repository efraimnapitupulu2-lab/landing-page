Tentang Saya

Saya Efraim Ricardo Hasiholan Napitupulu, mahasiswa Ilmu Komputer di Universitas Negri Medan. Di luar kegiatan akademik, saya cukup aktif mengikuti Unit Kegiatan Mahasiswa Kriten Prostestan (UKMKP), tempat saya belajar bekerja sama, mengatur waktu, dan mengambil tanggung jawab dalam kegiatan kerohanian.

Musik dan kerohanian menjadi cara saya menyeimbangkan rutinitas perkuliahan — baik sekadar mendengarkan, bermain alat musik, maupun saat teduh di waktu senggang.
